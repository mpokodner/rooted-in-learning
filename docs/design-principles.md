# Design principles — The Rooted Learner (Phase 1)

1. **Diagnosis before decoration.** Layout should make the problem (grouping from a single score, too-small instructional groups) visible before it sells a product.
2. **Earth first, terracotta as accent only.** Primary actions use earth fill. Secondary actions use earth outline. Terracotta is not a fill on new pages.
3. **Newsreader for new headings.** Unrebuilt pages keep Cal Sans. New surfaces use `--font-heading-new` (Newsreader) inside `.phase1`.
4. **No uppercase tracked eyebrows on new copy.** Sentence-case labels only.
5. **Motion is optional.** Honor `prefers-reduced-motion`. New pages do not use `.reveal`.
6. **Claims stay defensible.** No outcome promises, no FERPA/COPPA/SOC 2 seals, no named districts, no free-pilot language, no screener-replacement claims.
7. **One primary action per view.** AlignED conversation is the default CTA; supporting links stay quieter.
8. **Teacher as professional, not customer.** Copy addresses educators and leaders, not shoppers.
9. **Fake data in product illustrations.** “Student A”, grade 5 MD CCR codes — never real student names or live screenshots.
10. **Integrity of the existing site.** Additive URLs. Old routes stay until a flag is flipped. Do not restyle unrebuilt pages to prove a new system.
